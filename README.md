# Savanna downloads

Signed and notarized builds of **Savanna**, the Mac screen recorder where on-device AI writes and voices the narration.

**[Download the latest Savanna.dmg](https://github.com/Savanna-App/releases/releases/latest/download/Savanna.dmg)** · [All releases](https://github.com/Savanna-App/releases/releases) · [Website](https://savanna-app.github.io)

- For Macs with Apple silicon (M1 or later) on macOS 26.
- Open the DMG and drag Savanna to Applications. Savanna keeps itself up to date.
- Every release is signed with Developer ID (team `6H728M7XQK`) and notarized by Apple; a SHA-256 checksum is attached.

This repository only hosts the installers. The source code is private.
